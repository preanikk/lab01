Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки
зрения того, когда обнаруживаются ошибки?
в компилируемом языке ошибки находятся до запуска программы а на питоне ошибки находятся во время выполнения программы когда доходит до проблемной строки
2. Что делает команда dotnet run на самом деле — из каких двух шагов она состоит?
из компиляции преобразуеит код в исполняемый файл и запуска запускает этот файл
3. Зачем нужны папки bin/ и obj/ и почему их не нужно хранить в Git?
бин содержит готовые скомпелированные файлы о obj временные файлы сборки их не нужно хранить потмоу что они засорят репозиторий и будут конфликты
4. В чём разница между git commit и git push?
commit сохраняет файлфы локально на компьтере
push отправляет файлы на удаленный сервер например гитхаб
5. Чем отличаются конкатенация строк через + и интерполяция через $"..."? Какой
способ предпочтительнее и почему?
+ склеивает строки и требует обязательного преобразования чисел в текст а интерполяция ползволяет вставлять переменные прямо в текст через скобки. Интерполяция предпочтительнее потому что читабельнее короче и образует любые типы даных в строку
6. Что произойдёт, если разделить int на int, если результат должен быть дробным?
Как это исправить?
если разделить инт на инт то дробная часть отбросится, для дробного результата нужно чтобы одно число было дробного типа (double)
7. Чем const отличается от обычной переменной? Приведите свой пример, когда
стоит использовать const.
обычную переменную можно изменять в процессе работы программы а const задается один раз и не меняется например число пи, количество дней в неделе
8. Что такое top-level statements и чем они отличаются от классического class
Program{ static void Main() }?
top-level statements делает код короче проще и избавляет от лишнего шаблонного кода в отлиттчии от Program{ static void Main() }
